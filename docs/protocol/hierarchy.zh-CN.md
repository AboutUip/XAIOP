## 1. 范围

光标算子与层级。  
**文法优先：** [syntax.zh-CN.md](syntax.zh-CN.md)。

**对：** `>` = 创建空匿名对象 **并进入**，或已在对象上时 **再进入**；数组内 = 新元素。`<` = **仅上浮一层**；Root 上的 `<` = 语法错误。

**根开启符：** `>` / `-` 产生完整匿名根文档值。省略则得到**根片段**（如 `"a":{}`），**没有**外层匿名对象 — **不是** `{"a":{}}`。见 [syntax.zh-CN.md](syntax.zh-CN.md) §2。

---

## 2. 光标地址类型

光标定位到的地址 **必须** 为值类型 **`object`**，除非被后缀 `-` 固定为 **`array`**（第 9 节）。

创建/进入具名或匿名对象的 Label 表示 **object** 节点（除非适用后缀 `-`）。

---

## 3. 禁止裸 Label

仅有名字、**无**光标算子的 Label **禁止**（语法错误）：

```text
data
```

具名对象的必需形式：

```text
>data
```

---

## 4. 算子 `>` — 具名与匿名对象

### 4.1 具名对象

```text
语法: ><label>
语义: 相对当前光标，创建/进入子对象 <label>
```

单独的 `>a` 只在**当前**光标下创建具名子节点 `a`（该层 JSON 形如 `{ "a": {} }`）。**不会**再包一层外层匿名对象。匿名对象仅当使用独立 `>`（第 4.2 节）时存在。

### 4.2 匿名对象（`>`）

```text
语法: >
语义: 按 Cursor 上下文，对匿名对象做创建或更新
```

| Cursor | 语义 |
| --- | --- |
| Init / 尚无文档 | 创建空匿名**根**对象并进入 |
| 在**数组**内 | 创建新的空对象**元素**、压入并进入（每次 `>` … `<` 一个元素） |
| 已在**对象**上（含 `.` 之后的 Root） | **再进入**当前对象（修改）— **不**再嵌套一层匿名对象 |

这是创建匿名对象的**唯一**方式。不存在“创建空元素但不进入”的变体。`>name` **绝不**隐含事先存在外层匿名对象。

同址再访（对象 Cursor 上再次裸 `>`，或稍后写同一键）遵循创建或更新 / 覆盖（第 10 节）：后者胜出。生成器重复计数不在线协议职责内。

```text
>
>data
```

- 第一个 `>`：创建/进入匿名根。  
- `>data`：在其内创建/进入**具名**子节点 `data`。  
- 视图：`{ "data": {} }`。

```text
>
id:1
.
>
id:2
```

- `.` 之后 Cursor 在根对象；第二个 `>` **再进入**该根（修改）。  
- `id:2` 覆盖 `id:1` → `{ "id": 2 }`。

### 4.3 嵌套

```text
>data
>config
version:1
```

→ `{ "data": { "config": { "version": 1 } } }`

### 4.4 与 Content 共存

同一对象内，直接 Content 属性与嵌套对象/数组 **可以**共存：

```text
>data
a:b
>c
```

→ `{ "data": { "a": "b", "c": {} } }`

### 4.5 禁止同符号叠写

`>>label` **不得**支持。

合法多层下降：

1. 每行一次 `>` 动作（含空 `>`）。  
2. 经 `=` 的绝对路径（第 6 节）。

不同位置的行内组合（如 `>root>child`）**可以**作为一行上的相对路径 — 不是同符号叠写。

## 5. 算子 `<` — 上浮

### 5.1 仅上浮（`<`）

```text
语法: 恰为一行 <
语义: 光标移到父级一层。不创建节点。
```

Root 上的 `<` 为 **语法错误**。

### 5.2 上浮后进入（`<name`）

```text
语法: < 后紧跟标签名
语义: 上浮一层，再在父级创建/进入 <label>
```

### 5.3 作用

离开当前对象（含由 `>` 打开的数组元素），以便在父级（如包围数组）写下一个兄弟。

---

## 6. 算子 `=`（绝对 / 模糊路径）

```text
语法: =<path>
语义: 在已构建的层级树中匹配定位 <path>
```

1. 匹配为 **模糊**；不要求完整 Root 到目标路径。  
2. 路径越完整越精确。  
3. 多匹配时取 **第一个**。  
4. `=` **可以**与 `>` 组合（如 `=data>cor`）。

---

## 7. 算子 `!`（广播追加）

```text
语法: !<label>
语义: 将后续 Content 追加到所有匹配 <label> 的已有节点
```

---

## 8. 算子 `.`（重置）

```text
语法: .
语义: 光标重置到 Root；清除相对位置状态
```

层级不确定或生成准确度下降时，生成器 **应当**先发 `.`，再从 Root 用 `=` 或 `>` 重定位。不要用额外的 `<` / `>` 猜层级。

---

## 9. 数组算子 `-`

`-` **打开**数组。兄弟元素 **不用** `-` 分隔。

`>` 打开对象元素后，光标留在该元素内，直到 `<` / `<name` / `.` 回到数组。

### 9.1 后缀 `-`（具名数组）

```text
>data
>tags-
:a
:b
```

→ `{ "data": { "tags": ["a", "b"] } }`

### 9.2 独立 `-`（匿名数组）

```text
-
:a
:b
:c
```

→ `[ "a", "b", "c" ]`

数组内再写 `-`，打开作为下一元素的 **嵌套**匿名数组并进入。

### 9.3 数组层 vs 元素内

| 在数组层 | `>` 之后在元素内 |
| --- | --- |
| `:v` → 标量元素 | Content 写在当前对象 |
| `key:value` → **单行对象元素**（规范性：单属性 `{k:v}`；光标仍在数组层） | 允许嵌套结构 |
| `>` → 对象元素 **并进入** | 更深嵌套 |
| `-` → 嵌套数组元素 | — |
| | `<` → 回到数组 |

### 9.4 示例

```text
-
>
<
>
<
```

→ `[ {}, {} ]`

```text
-
>
a:1
b:2
<
>
c:3
<
```

→ `[ { "a": 1, "b": 2 }, { "c": 3 } ]`

```text
-
a:b
a:b
```

→ `[ { "a": "b" }, { "a": "b" } ]`

```text
-
>
<
>
<
:a
:b
```

→ `[ {}, {}, "a", "b" ]`

## 10. 创建或更新与覆盖 / 丢弃

### 10.1 创建或更新

无需显式声明创建或修改。缺失路径被创建；兼容的继续使用则追加/更新/**再进入**。

示例：

- 同父下 `>name` 后再 `>name`（仍为 object）→ 再进入。  
- Cursor 已在对象上时的裸 `>` → 再进入该对象（第 4.2 节）。  
- Cursor 在数组内时的裸 `>` → **新建**元素（不是再进入）。

### 10.2 覆盖 / 丢弃

稍后光标动作对已填充地址重定类型或替换（object ↔ array 等）：后者胜出；先前载荷丢弃。清空 / JSON 物化属 SDK 职责。

---

## 11. 顺序无关性

1. `.` 加绝对 / 更完整的 `=` 路径 **可以**得到顺序无关的树形。  
2. 相对 `>` / `<` 引入顺序依赖。  
3. 顺序无关 **不是**默认保证。  
4. 需要该保证的应用 **必须**限制生成器只用 `.` + `=`，并禁止相对算子。
