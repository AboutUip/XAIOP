## 1. 范围

光标算子与层级。  
**文法优先：** [syntax.zh-CN.md](syntax.zh-CN.md)。

**对：** `>` = 创建空匿名对象 **并进入**，或已在对象上时 **再进入**；数组内 = 新元素。`<` = **仅上浮一层**；Root 上的 `<` = 语法错误。

**根开启符：** `>` / `-` 产生完整匿名根文档值。省略则得到**根片段**（如 `"a":{}`），**没有**外层匿名对象 — **不是** `{"a":{}}`。见 [syntax.zh-CN.md](syntax.zh-CN.md) §2。

---

## 2. 光标地址类型

光标定位到的地址 **必须** 为值类型 **`object`**，除非被后缀 `-` 固定为 **`array`**（第 11 节）。

创建/进入具名或匿名对象的 Label 表示 **object** 节点（除非适用后缀 `-`）。

---

## 3. 禁止裸 Label

仅有名字、**无**光标算子的 Label **禁止**（语法错误）：

```text
data
```

具名对象的必需形式：

```text
>data
```

---

## 4. 算子 `>` — 具名与匿名对象

### 4.1 具名对象

```text
语法: ><label>
语义: 相对当前光标，创建/进入子对象 <label>
```

单独的 `>a` 只在**当前**光标下创建具名子节点 `a`（该层 JSON 形如 `{ "a": {} }`）。**不会**再包一层外层匿名对象。匿名对象仅当使用独立 `>`（第 4.2 节）时存在。

### 4.2 匿名对象（`>`）

```text
语法: >
语义: 按 Cursor 上下文，对匿名对象做创建或更新
```

| Cursor | 语义 |
| --- | --- |
| Init / 尚无文档 | 创建空匿名**根**对象并进入 |
| 在**数组**内 | 创建新的空对象**元素**、压入并进入（每次 `>` … `<` 一个元素） |
| 已在**对象**上（含 `.` 之后的 Root） | **再进入**当前对象（修改）— **不**再嵌套一层匿名对象 |

这是创建匿名对象的**唯一**方式。不存在“创建空元素但不进入”的变体。`>name` **绝不**隐含事先存在外层匿名对象。

同址再访（对象 Cursor 上再次裸 `>`，或稍后写同一键）遵循创建或更新 / 覆盖（第 12 节）：后者胜出。生成器重复计数不在线协议职责内。

```text
>
>data
```

- 第一个 `>`：创建/进入匿名根。  
- `>data`：在其内创建/进入**具名**子节点 `data`。  
- 视图：`{ "data": {} }`。

```text
>
id:1
.
>
id:2
```

- `.` 之后 Cursor 在根对象；第二个 `>` **再进入**该根（修改）。  
- `id:2` 覆盖 `id:1` → `{ "id": 2 }`。

### 4.3 嵌套

```text
>data
>config
version:1
```

→ `{ "data": { "config": { "version": 1 } } }`

### 4.4 与 Content 共存

同一对象内，直接 Content 属性与嵌套对象/数组 **可以**共存：

```text
>data
a:b
>c
```

→ `{ "data": { "a": "b", "c": {} } }`

### 4.5 禁止同符号叠写

`>>label` **不得**支持。

合法多层下降：

1. 每行一次 `>` 动作（含空 `>`）。  
2. 经 `=` 的绝对路径（第 6 节）。

不同位置的行内组合（如 `>root>child`）**可以**作为一行上的相对路径 — 不是同符号叠写。

## 5. 算子 `<` — 上浮

### 5.1 仅上浮（`<`）

```text
语法: 恰为一行 <
语义: 光标移到父级一层。不创建节点。
```

Root 上的 `<` 为 **语法错误**。

### 5.2 上浮后进入（`<name`）

```text
语法: < 后紧跟标签名
语义: 上浮一层，再在父级创建/进入 <label>
```

### 5.3 作用

离开当前对象（含由 `>` 打开的数组元素），以便在父级（如包围数组）写下一个兄弟。

---

## 6. 算子 `=`（模糊定位）

```text
语法: =<path>
语义: 在已建树中模糊匹配定位 <path>；移动单光标
```

1. 路径段用 `>` 分隔（如 `=data>cor`）。  
2. 匹配为 **模糊**；不要求从 Root 写全路径。  
3. 路径越完整越精确。  
4. 多命中取 **第一个**（确定性文档序）。  
5. 零命中 → **语法错误**（**不**创建）。  
6. **不**创建节点。目标 **必须** 为 object 或 array 地址。  
7. **向前跨相：** `=` 在**迄今已建整棵树**上定位，含更早 `.` 相位写入的节点（整文档 / 累积 parse）。

对照：`@` 自 Root 精确且**创建**缺失段（本相）；`!` 对所有完整路径片段匹配广播（同样看整棵已建树）。

---

## 7. 算子 `@`（自 Root 精确路径；创建或进入）

```text
语法: @<path>
语义: 自 Root 沿 <path> 精确下降；缺失对象段则创建；移动单光标；不做模糊搜索
```

1. 路径段用 `>` 分隔（如 `@a>b`）。  
2. 从文档 Root（或片段根）起按连续键 **精确** 下降 — **不**深搜旁支。  
3. 每段 **必须** 为完整标签（禁止子串 / 残缺标签匹配）。  
4. 段 **缺失** 或为标量 → 在该键 **创建** 空对象并进入（本相创建）。  
5. 段已是 **object** → 进入；已是 **array** 且为本路径**末段** → 进入该数组；数组出现在中段 → 替换为 `{}` 后继续。  
6. **不**进入广播模式。  
7. 与 `=` / `!` 不同：`@` 不只做跨相定位；缺失路径在本相补齐。Root 精确路径上已有的先前相节点仍进入。

---

## 8. 算子 `!`（广播路径匹配）

```text
语法: !<path>
语义: 定位每一个完整路径片段匹配；进入广播多光标模式
```

### 8.1 匹配

1. 路径段用 `>` 分隔（如 `!test`、`!a>b`）。  
2. 在迄今已建的 **整棵树** 上搜索完整路径片段匹配（连续键），含 **更早 `.` 相位** 的节点（向前跨相 / 累积）。  
3. **外层剪枝：** 从某子键开始一旦命中，该子键子树内 **不再** 为同一次查询收集更多命中；兄弟 / 其它分支继续。  
4. 残缺标签不匹配（例如不存在 `te` 节点时，`!te` 不能命中 `test`）。  
5. 目标 **必须** 为 object 或 array。  
6. 零命中 → **语法错误**（**不**创建）。

### 8.2 广播模式

1. 成功后，Cursor 成为匹配处的 **克隆集合**。  
2. 后续 Structure / Content 行对 **每一个** Cursor 各执行一遍。  
3. **任一** Cursor 失败 → 整行 **失败**（文档错误）。  
4. 广播激活时再发 `!` / `@` / `=` → **语法错误**（须先发 `.`）。  
5. 广播激活时 **允许** `&path`（第 9 节）— 路径相对各 Cursor。  
6. `.` 将 Cursor 重置到 Root 并 **退出** 广播模式。  
7. `!` 之后写入走普通 XAIOP。`@` 可创建；`!` / `=` 只定位。

流式：按 `.` 发 Diff 的实现，对含 `=` / `!` / `&` 的相位 **必须** 解析**累积前缀**，使定位与删除看见先前相。`@` 创建或进入 **可以** 保持相位局部。

---

## 9. 算子 `&`（按路径删除）

```text
语法: &<path>
语义: 沿 <path> 删除最深键；不移动 Cursor
```

1. 路径段用 `>` 分隔（与 `@` 同形，如 `&a`、`&a>b`）。裸 `&`（空路径）**禁止**（语法错误）。  
2. **单光标：** 路径自 Root **绝对**；删除最深键；**不**移动 Cursor。  
3. **目标缺失：** 静默 **无操作**。  
4. 要求文档根为 **object**。禁止用于 **数组根** / **片段根**。不得删除文档根本身。  
5. **可以** 删除整个具名数组值（该键对应的数组）。**无** 数组元素下标删除。  
6. 若删除会去掉 **Cursor 链** 上的节点（当前 Cursor 值或栈上任一祖先）→ **语法错误**。  
7. **广播**（`!` 激活）：**允许**。路径相对 **各** Cursor。各 Cursor 上目标缺失 = 无操作。任一 Cursor 发生 Cursor 链冲突 → 整行失败（与其它广播失败相同）。  
8. `.` 仍只重置 Cursor / 退出广播；与 `&` 无特殊交互。  
9. 之后对同一地址再写 = **重新创建**（普通创建或更新）。

流式：含 `&` 的相位对按 `.` 的 Diff **必须** 用累积前缀 parse（同 `=` / `!`）。`&` 的 cover 式 Diff 整形为 **仅 SDK** 选项（默认关）：连续 `&` 后注入 `.`、最深键 `null` 墓碑 Diff、再用 `>` 链恢复 — **不属于** 线文法。

---

## 10. 算子 `.`（重置）

```text
语法: .
语义: 光标重置到 Root；清除相对位置状态；退出广播模式
```

层级不确定或生成准确度下降时，生成器 **应当**先发 `.`，再从 Root 用 `=` / `@` / `>` 重定位。不要用额外的 `<` / `>` 猜层级。

## 11. 算子 #（自定义注解传递）

`	ext
语法: # <任意文本至行尾>
语义: 自定义注解传递；协议不解释 # 之后内容；无 Cursor / JSON 树副作用
`

1. **官方名称：** **自定义注解传递**（custom annotation transmission）。**禁止**在规范性文本中把本原语定义成「注释」。
2. **必须**为**独立单行**，且该逻辑行以 # 开头（# 为行首字符；行首空白则**不是**本原语）。
3. **位置不限** — 文档任意处，只要是独立单行即可。
4. 解析器 **必须**识别此类行且 **不得**因此移动 Cursor、写入/删除树、结束 Block 或进入/退出广播。
5. # 之后的文本 **无协议语义**（可为空，即单独一行 #）。应用如何保留或上送属实现范围。
6. Content 值中的 #（如 
ote:#x）**不是**本原语 — 仍按 Content 规则解析。

## 12. 数组算子 `-`

`-` **打开**数组。兄弟元素 **不用** `-` 分隔。

`>` 打开对象元素后，光标留在该元素内，直到 `<` / `<name` / `.` 回到数组。

### 12.1 后缀 `-`（具名数组）

```text
>data
>tags-
:a
:b
```

→ `{ "data": { "tags": ["a", "b"] } }`

**创建或再进入（与 `>name` 对象对齐）：**

1. 键 `name` 缺失或不是数组 → 创建空数组、赋值并进入。  
2. 键 `name` 已是数组 → **再进入同一数组**；后续元素 **追加**（**不**整段替换）。  
3. `.` 之后再 `>name-` 因此可跨相位增长数组。

```text
>
>tags-
:a
.
>
>tags-
:b
```

→ `{ "tags": ["a", "b"] }`

### 12.2 独立 `-`（匿名数组）

```text
-
:a
:b
:c
```

→ `[ "a", "b", "c" ]`

数组内再写 `-`，打开作为下一元素的 **嵌套**匿名数组并进入。

### 12.3 数组层 vs 元素内

| 在数组层 | `>` 之后在元素内 |
| --- | --- |
| `:v` → 标量元素 | Content 写在当前对象 |
| `key:value` → **单行对象元素**（规范性：单属性 `{k:v}`；光标仍在数组层） | 允许嵌套结构 |
| `>` → 对象元素 **并进入** | 更深嵌套 |
| `-` → 嵌套数组元素 | — |
| | `<` → 回到数组 |

### 12.4 示例

```text
-
>
<
>
<
```

→ `[ {}, {} ]`

```text
-
>
a:1
b:2
<
>
c:3
<
```

→ `[ { "a": 1, "b": 2 }, { "c": 3 } ]`

```text
-
a:b
a:b
```

→ `[ { "a": "b" }, { "a": "b" } ]`

```text
-
>
<
>
<
:a
:b
```

→ `[ {}, {}, "a", "b" ]`

## 13. 创建或更新与覆盖 / 丢弃

### 13.1 创建或更新

无需显式声明创建或修改。缺失路径被创建；兼容的继续使用则追加/更新/**再进入**。

示例：

- 同父下 `>name` 后再 `>name`（仍为 object）→ 再进入。  
- 同父下 `>name-` 后再 `>name-`（仍为 array）→ 再进入；元素 **追加**。  
- Cursor 已在对象上时的裸 `>` → 再进入该对象（第 4.2 节）。  
- Cursor 在数组内时的裸 `>` → **新建**元素（不是再进入）。  
- `&path` 删除某键后，再写同一地址 = **重新创建**。

### 13.2 覆盖 / 丢弃

稍后光标动作对已填充地址重定类型或替换（object ↔ array 等）：后者胜出；先前载荷丢弃。清空 / JSON 物化属 SDK 职责。

示例：

- 键上是 object，再 `>name-` → 丢弃 object，安装新数组。  
- 键上是 array，再 `>name` → 丢弃 array，安装新对象。  
- 键上已是 array，再 `>name-` → **不**丢弃；再进入并追加（第 11.1 节）。

## 14. 顺序无关性

1. `.` 加绝对 / 更完整的 `=` / `@` 路径 **可以**得到顺序无关的树形。  
2. 相对 `>` / `<` 引入顺序依赖。  
3. 顺序无关 **不是**默认保证。  
4. 需要该保证的应用 **必须**限制生成器只用 `.` + `=` / `@`，并禁止相对算子。
