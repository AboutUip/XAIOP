## 0. 用途

“一行可以写什么？”的唯一入口。  
细节：[boundary.zh-CN.md](boundary.zh-CN.md) · [hierarchy.zh-CN.md](hierarchy.zh-CN.md) · [content.zh-CN.md](content.zh-CN.md) · [streaming.zh-CN.md](streaming.zh-CN.md)

---

## 1. 硬性规则（MUST）

1. **禁止裸 Label** — 仅有名字的行（如 `data`）为语法错误。  
2. **`>`** 创建空匿名对象 **并进入**（创建**匿名**对象的唯一方式）。  
3. **`>name`** 在当前光标创建/进入**具名**子节点 — **不是**外层匿名包裹。  
4. **`<`** 仅上浮一层；**Root 上的 `<` 为语法错误**。  
5. **`<name`** 上浮一层，再创建/进入 `name`。  
6. **不得**用括号配对、缩进或多字符结束标记作边界。  
7. **无** Block 结束标记 — 下一 Label 行或 EOF 结束 Block。  
8. 值中 **不得**含换行。  
9. Content 仅按 **第一个** `:` 分割。  
10. **`-` 不是数组兄弟分隔符** — 它打开数组（或作为下一个元素的嵌套数组）。  
11. **根声明**（第 2 节）：意图存在根对象或根数组时，以 `>` 或 `-` 开头；不意图根容器时省略。

---

## 2. 根声明

存在根容器时，生成器 **必须** 明确根类型：

| 意图 | 首条结构行 | 含义 |
| --- | --- | --- |
| 根为**对象** | 独立 `>` | 在 Root 创建空匿名对象 **并进入** |
| 根为**数组** | 独立 `-` | 在 Root 创建空匿名数组 **并进入** |
| **无**根对象/数组 | 省略开头的 `>` / `-` | 可直接从 `>name`、Content、`=`、`!` 等开始 |

1. 若意图根为**对象**或**数组**，Stream **必须**分别以 `>` 或 `-` 开头 — 立即告知解析器根是空对象还是空数组。  
2. 若**不**意图根对象/数组，生成器 **不必**写开头的 `>` 或 `-`。  
3. 单独的 `>name` **不**声明匿名根对象。

**有根对象：**

```text
>
>meta
name:demo
```

→ `{ "meta": { "name": "demo" } }`

**有根数组：**

```text
-
:a
:b
```

→ `[ "a", "b" ]`

**无根容器：**

```text
>meta
name:demo
```

→ `{ "meta": { "name": "demo" } }`（Root 下的具名子节点；无匿名根开启）

## 3. 行文法

| 行 | 种类 | 含义 |
| --- | --- | --- |
| `>` | 结构 | 创建/进入**匿名**对象 — **始终进入**；绝不由 `>name` 隐含 |
| `>name` | 结构 | 在当前光标创建/进入**具名**子节点（无外层匿名包裹） |
| `>name-` | 结构 | 创建/进入具名数组 |
| `-` | 结构 | 创建/进入匿名数组（或作为下一元素的嵌套数组） |
| `<` | 结构 | 仅上浮一层 |
| `<name` | 结构 | 上浮一层，再创建/进入 `name` |
| `key:value` | 内容 | **当前**对象的属性 |
| `:value` | 内容 | 标量 / 匿名值 |
| `.` | 结构 | 光标重置到 Root |
| `=path` | 结构 | 绝对 / 模糊定位 |
| `!name` | 结构 | 向匹配节点广播追加 |

**禁止：** 裸 Label · `>>x` 叠写 · Root 上的 `<` · 多行值。

---

## 4. `>` / `<` 对

- **`>`** — 创建空匿名对象并进入（对象与数组内规则相同）。离开前的写入均进入该对象。  
- **`<`** — 回到父级；不创建；Root 非法。  
- **`<name`** — 上浮后在父级创建/进入 `name`。

```text
>
>data
```

```text
>
x:1
```

→ `{ "x": 1 }`，直到 `<` 或其他离开。

---

## 5. 对象嵌套

```text
>data
>config
version:1
```

→ `{ "data": { "config": { "version": 1 } } }`

```text
>data
a:b
>c
```

→ `{ "data": { "a": "b", "c": {} } }`（最后一行 `>` 后光标在 `c` 内）。

---

## 6. 数组

用 `-` 或 `>name-` 打开。**不要**在兄弟元素之间写 `-`。  
根为数组的 Stream **必须**以 `-` 开头（第 2 节）。

| 光标 | 后续行 |
| --- | --- |
| **数组层** | `:v` · 单行 `key:value` · `>`（对象元素并进入）· `-`（嵌套数组元素） |
| **元素内**（`>` 之后） | 写在该对象上 · 可嵌套结构 · **`<`** 回到数组 |

### 标量

```text
-
:a
:b
:c
```

→ `[ "a", "b", "c" ]`

### 空对象

```text
-
>
<
>
<
```

→ `[ {}, {} ]`

### 可填充对象

```text
-
>
a:1
b:2
<
>
c:3
<
```

→ `[ { "a": 1, "b": 2 }, { "c": 3 } ]`

### 单行对象元素（停留在数组层）

```text
-
a:b
a:b
```

→ `[ { "a": "b" }, { "a": "b" } ]`

### 混合

```text
-
>
<
>
<
:a
:b
```

→ `[ {}, {}, "a", "b" ]`

### 具名数组

```text
>data
>tags-
:a
:b
```

→ `{ "data": { "tags": ["a", "b"] } }`

## 7. 内容类型（摘要）

| 规则 | 结果 |
| --- | --- |
| `key:value` | 属性 |
| `:value` | 标量 / 匿名 |
| 可解析为 int | int |
| 恰为 `true`/`false` | bool |
| 其他 | string |
| `:` 后、值前有空格 | 强制 string |

---

## 8. 边界 / 覆盖（摘要）

- Label 以 `LF` 或 `CRLF` 结束；Content 直至下一 Label；末 Block 在 EOF；一行一个 Label。  
- 同一地址稍后重定类型：覆盖/丢弃（由 SDK 清空）。
