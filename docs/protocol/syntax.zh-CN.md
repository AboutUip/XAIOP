## 0. 用途

“一行可以写什么？”的唯一入口。  
细节：[boundary.zh-CN.md](boundary.zh-CN.md) · [hierarchy.zh-CN.md](hierarchy.zh-CN.md) · [content.zh-CN.md](content.zh-CN.md) · [streaming.zh-CN.md](streaming.zh-CN.md)

## 1. 硬性规则（MUST）

1. **禁止裸 Label** — 仅有名字的行（如 `data`）为语法错误。  
2. **`>`** 按 Cursor 上下文创建或再进入匿名对象（见第 4 节 / [hierarchy.zh-CN.md](hierarchy.zh-CN.md) §4.2）：开根、**新数组元素**、或**再进入**当前对象 — 创建**匿名**对象的唯一方式。  
3. **`>name`** 在当前光标创建/进入**具名**子节点 — **不是**外层匿名包裹。  
4. **`<`** 仅上浮一层；**Root 上的 `<` 为语法错误**。  
5. **`<name`** 上浮一层，再创建/进入 `name`。  
6. **不得**用括号配对、缩进或多字符结束标记作边界。  
7. **无** Block 结束标记 — 下一 Label 行或 EOF 结束 Block。  
8. 值中 **不得**含换行。  
9. Content 仅按 **第一个** `:` 分割。  
10. **`-` 不是数组兄弟分隔符** — 它打开数组（或作为下一个元素的嵌套数组）。  
11. **根开启符**（第 2 节）：`>` / `-` 声明**完整**匿名根文档值；省略则得到**根片段**（无外层对象）— **不等于** `{"a":{}}`。  
12. **数组单行对象**（第 6.1 节）：在数组层，`key:value` 表示一个完整的单属性对象元素（光标仍停留在数组层）。

---

## 2. 根声明 — 完整文档 vs 片段

开头的独立 `>` 或 `-` **声明并进入**匿名根**对象**或**数组**。该匿名容器**就是** JSON 物化时的文档根值。

若以 `>name`（或 Root 层 Content）开头且**没有**先写 `>` / `-`，则**不会**创建外层匿名对象。Stream 是**根片段**：Root 上的具名绑定。记法为 `"a":{}` — **不是** JSON 文档 `{"a":{}}`。

| 情形 | 开启符 | 结果 |
| --- | --- | --- |
| 完整 JSON **数组**文档 | `-`（**必须**） | 如 `["a","b"]` |
| 完整 JSON **对象**文档（进入匿名根） | `>`（意图如此时**必须**） | 如 `{"a":{}}`、`{"x":1}` |
| 根**片段**（无外层匿名对象） | 省略 `>` / `-`；用 `>name` / Content | 语义 `"a":{}` — **不能**单独作为 JSON 文档 |

**不同产物（规范性）：**

```text
>
>a
```

→ JSON 文档 `{ "a": {} }` — **存在**外层匿名对象（由 `>` 声明）。

```text
>a
```

→ 根片段 `"a":{}` — **没有**外层匿名对象；**不能**独立构成合法 JSON 文档。

```text
>
x:1
```

→ `{ "x": 1 }` — 匿名根 + 直接 Content。

```text
-
:a
:b
```

→ `[ "a", "b" ]` — 根数组。

## 3. 行文法

| 行 | 种类 | 含义 |
| --- | --- | --- |
| `>` | 结构 | 匿名对象：开根 / **新数组元素** / **再进入**当前对象 |
| `>name` | 结构 | 在当前光标创建/进入**具名**子节点（无外层匿名包裹） |
| `>name-` | 结构 | 创建/进入具名数组 |
| `-` | 结构 | 创建/进入匿名数组（或作为下一元素的嵌套数组） |
| `<` | 结构 | 仅上浮一层 |
| `<name` | 结构 | 上浮一层，再创建/进入 `name` |
| `key:value` | 内容 | **当前**对象的属性 |
| `:value` | 内容 | 标量 / 匿名值 |
| `.` | 结构 | 光标重置到 Root |
| `=path` | 结构 | 绝对 / 模糊定位 |
| `!name` | 结构 | 向匹配节点广播追加 |

**禁止：** 裸 Label · `>>x` 叠写 · Root 上的 `<` · 多行值。

---

## 4. `>` / `<` 对

- **`>`** — 按 Cursor：开匿名根、压入并进入新数组元素、或**再进入**当前对象（修改）。绝不由 `>name` 隐含。离开前的写入均进入当前对象。  
- **`<`** — 回到父级；不创建；Root 非法。  
- **`<name`** — 上浮后在父级创建/进入 `name`。

```text
>
>data
```

```text
>
x:1
```

→ `{ "x": 1 }`，直到 `<` 或其他离开。

---

## 5. 对象嵌套

```text
>data
>config
version:1
```

→ `{ "data": { "config": { "version": 1 } } }`

```text
>data
a:b
>c
```

→ `{ "data": { "a": "b", "c": {} } }`（最后一行 `>` 后光标在 `c` 内）。

---

## 6. 数组

用 `-` 或 `>name-` 打开。**不要**在兄弟元素之间写 `-`。  
根为数组的 Stream **必须**以 `-` 开头（第 2 节）。

| 光标 | 后续行 |
| --- | --- |
| **数组层** | `:v` · 单行 `key:value`（第 6.1 节）· `>`（对象元素并进入）· `-`（嵌套数组元素） |
| **元素内**（`>` 之后） | 写在该对象上 · 可嵌套结构 · **`<`** 回到数组 |

### 6.1 单行对象元素（规范性）

当光标在**数组层**时，键**非空**的 Content 行：

```text
key:value
```

**必须**解析为**一个完整的数组元素**，其值为单属性对象 `{ "key": <类型化后的值> }`。

1. 光标**必须仍停留**在数组层（**不**进入该对象）。  
2. 这是元素的**完整**声明，不是数组的属性。  
3. 与 `>` … Content … `<` **不同**：后者创建可填充对象元素并**进入**。  
4. 元素需要**零个或多个**属性或嵌套结构时，用 `>`。

```text
-
a:solo
```

→ `[ { "a": "solo" } ]`

### 标量

```text
-
:a
:b
:c
```

→ `[ "a", "b", "c" ]`

### 空对象

```text
-
>
<
>
<
```

→ `[ {}, {} ]`

### 可填充对象

```text
-
>
a:1
b:2
<
>
c:3
<
```

→ `[ { "a": 1, "b": 2 }, { "c": 3 } ]`

### 单行对象元素（数组层）

```text
-
a:b
a:b
```

→ `[ { "a": "b" }, { "a": "b" } ]`

### 混合

```text
-
>
<
>
<
:a
:b
```

→ `[ {}, {}, "a", "b" ]`

### 具名数组

```text
>data
>tags-
:a
:b
```

→ `{ "data": { "tags": ["a", "b"] } }`

## 7. 内容类型（摘要）

| 规则 | 结果 |
| --- | --- |
| `key:value` | 属性 |
| `:value` | 标量 / 匿名 |
| 可解析为 int | int |
| 恰为 `true`/`false` | bool |
| 其他 | string |
| `:` 后、值前有空格 | 强制 string |

---

## 8. 边界 / 覆盖（摘要）

- Label 以 `LF` 或 `CRLF` 结束；Content 直至下一 Label；末 Block 在 EOF；一行一个 Label。  
- 同一地址稍后重定类型：覆盖/丢弃（由 SDK 清空）。
