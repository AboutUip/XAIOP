## 1. 范围

文档 **状态** 标签、规范 **包版本** 与变更策略。

---

## 2. 文档状态

每份规范文档 **必须** 声明恰好一种状态：

| 状态 | 含义 |
| --- | --- |
| `Reserved` | 占位；内容非规范性 |
| `Draft` | 活跃工作稿；可发生不兼容变更 |
| `Frozen` | 已编号包的封存规范性文本；变更须升包版本 |
| `Stable` | 正式 Stable 系列已接受 |
| `Deprecated` | 已替代；保留备查 |
| `Withdrawn` | 不再属于规范 |

### 2.1 当前阶段

本包中的协议线文档在包版本 **`0.2.1`** 下为 **`Frozen`**。  
仍属编辑脚手架的基础 / 需求文档 **可以** 仍标 `Draft`；若与 Frozen 协议文本冲突，**以协议文本为准**。

---

## 3. 规范包版本

1. 包版本出现在文档头（如 `0.2.1`）。  
2. **`Frozen`** 包使用不含 `-draft` 的纯 SemVer。  
3. 对 Frozen 协议文档的不兼容变更 **必须** 升包版本（改变规范性含义的澄清至少升次版本；破坏线格式则升主版本）。

## 4. 变更策略（Frozen）

协议文档在 `0.2.1` 为 `Frozen` 时：

1. 不改变含义的编辑性笔误 **可以** 原地修正。  
2. 规范性含义变更 **必须** 以新包版本发布。  
3. 规范性含义变更时，中文镜像 **必须** 与英文权威文本同批更新。

---

## 5. Reserved 文档

`Reserved` 文档或索引条目：

1. **不得** 被引为建立一致性要求。  
2. **可以** 列出计划中的文档 ID 与标题。  
3. **必须** 声明语法与语义尚未发布。

本冻结未包含（若日后引入）：`PROT-MODEL`、`PROT-ERROR`、`PROT-EXT`。

---

## 6. 与仓库状态的关系

仓库根 README 可用散文描述项目成熟度。  
一致性讨论以本文档集中的规范状态标签为准。
